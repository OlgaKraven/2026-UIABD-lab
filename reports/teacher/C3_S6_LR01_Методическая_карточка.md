# C3_S6_LR01. Установка сервера и первичная настройка

> Материал преподавателя. Не включать в студенческий шаблон и публичную страницу стенда.

## Цель и формируемый навык

**Цель:** Развернуть изолированный учебный экземпляр MySQL и зафиксировать его основные параметры.

**Навык:** Устанавливать сервер, выбирать каталог данных, порт и режим службы, затем подтверждать готовность экземпляра.

**Компетенции:** ОК 01, ПК 7.1, ПК 7.2.

**Связь с лекцией:** [Установка и первичная настройка MySQL](https://olgakraven.github.io/2026-UIABD3-lecture/?topic=s06-02-install-initial-configuration&slide=1).

## Индивидуализация

Назначьте студенту один вариант от **01 до 30** по ведомости группы. Номер сохраняется для всех работ семестра; параметры берутся из соответствующей строки файла `inputs/variants/c3-s6-variants.csv`. Для работ с инцидентом к номеру привязана одноимённая карточка случая.

## Исходные данные

- Учебная виртуальная машина Windows с правами администратора.
- Карточка варианта: порт, имя службы и каталог данных.
- Дистрибутив MySQL Community Server 8.4, предоставленный преподавателем.
- Форма журнала установки без паролей.

## Ожидаемый и эталонный результат

**Ожидаемый результат:** Журнал установки и карта конфигурации экземпляра.

**Эталонная проверка:** Служба работает, подключение успешно, три параметра совпадают с вариантом.

**Ключ к ситуации:** Обычно расходятся имя службы, порт клиента и фактический параметр port либо служба не стартовала после конфигурирования.

## Правильная последовательность действий

1. Сверьте контрольную сумму и имя выданного дистрибутива.
2. Установите серверный компонент и задайте параметры варианта.
3. Настройте запуск экземпляра как службы.
4. Зафиксируйте фактические пути к исполняемым файлам, конфигурации и данным.
5. Запустите службу и выполните подключение клиентом.
6. Получите версию, порт и каталог данных запросом к серверу; сопоставьте их с вариантом.

## Допустимые варианты

- Установка из MSI через MySQL Configurator.
- Ручное развёртывание ZIP в подготовленной учебной VM.

## Типичные ошибки и сообщения

**Методическая ошибка:** Установка подтверждена только скриншотом мастера, без ответа сервера.

- `ERROR 2003 (HY000): Can't connect to MySQL server`
- `The service name is invalid`
- `Access denied for user`
