# C4_S8_LR05. Сравнение MySQL и PostgreSQL по заданной учебной ситуации

> Материал преподавателя. Не включать в студенческий шаблон и публичную страницу стенда.

## Цель и формируемый навык

**Цель:** Выполнить одинаковый минимальный сценарий на MySQL и PostgreSQL и выбрать платформу по наблюдаемым различиям.

**Навык:** Сравнивать установку, роли, типы, отдельные конструкции SQL и средства наблюдения без ложной универсализации.

**Компетенции:** ОК 01, ПК 7.1, ПК 7.2, ПК 7.3.

**Связь с лекцией:** [Сравнение MySQL и PostgreSQL](https://olgakraven.github.io/2026-UIABD4-lecture/?topic=s08-05-database-platform-comparison&slide=1).

## Индивидуализация

Назначьте студенту один вариант от **01 до 30** по ведомости группы. Номер сохраняется для всех работ семестра; параметры берутся из соответствующей строки файла `inputs/variants/c4-s8-variants.csv`. Для работ с инцидентом к номеру привязана одноимённая карточка случая.

## Исходные данные

- Одинаковая учебная ситуация и минимальная схема для двух платформ.
- MySQL 8.4 и PostgreSQL 18 в изолированных экземплярах.
- Матрица критериев: установка, роли, типы, запрос, мониторинг.
- Вариант приоритета организации.

## Ожидаемый и эталонный результат

**Ожидаемый результат:** Сравнительная матрица MySQL/PostgreSQL и обоснованный выбор.

**Эталонная проверка:** Пять критериев подтверждены на обеих платформах, выбор следует из приоритета варианта.

**Ключ к ситуации:** Ошибки возникают при прямом переносе синтаксиса учётных записей, типов или служебных представлений.

## Правильная последовательность действий

1. Разверните минимальную схему и одинаковые строки на обеих платформах.
2. Создайте роль чтения и проверьте разрешённую/запрещённую операцию.
3. Выполните один запрос с группировкой и сравните результат.
4. Сопоставьте выбранные типы и синтаксические различия.
5. Найдите штатный источник состояния подключений/активности на каждой платформе.
6. Заполните матрицу фактов и выберите платформу по приоритету варианта.

## Допустимые варианты

- Локальные изолированные экземпляры.
- Подготовленные преподавателем серверы при одинаковой версии и наборе данных.

## Типичные ошибки и сообщения

**Методическая ошибка:** Сравнение превращается в реферат или переносит синтаксис одной СУБД на другую без проверки.

- `MySQL ERROR 1045`
- `PostgreSQL FATAL: role does not exist`
- `permission denied`
