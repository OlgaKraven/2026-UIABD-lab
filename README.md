# МДК.07.01 — лабораторные работы

Публичный учебный стенд для дисциплины **«Управление и автоматизация баз данных»** по специальности 09.02.07. В репозитории находятся 22 двухчасовые лабораторные работы, исходные данные, 30 индивидуальных вариантов, редактируемые DOCX-шаблоны и закрытый комплект методических карточек преподавателя.

## Структура курса

| Курс | Семестр | Работ | Основной блок |
| ---: | ---: | ---: | --- |
| 3 | 6 | 7 | Сервер баз данных и администрирование его компонентов |
| 4 | 7 | 10 | Запросы, автоматизация и требования к конфигурации |
| 4 | 8 | 5 | Наблюдение, инциденты и сравнение платформ |

MySQL 8.4 используется как основная платформа. PostgreSQL 18 включён в сравнительную работу последнего семестра. Для каждого семестра подготовлена матрица вариантов 01–30; номер студента сохраняется на протяжении семестра.

## Где что находится

- `content/labs.json` — единый источник данных публичного сайта;
- `course-3/`, `course-4/` — карточки заданий для студентов;
- `inputs/` — SQL, CSV, JSON, журналы, конфигурации и матрицы вариантов;
- `reports/student/` — 22 редактируемых DOCX-шаблона;
- `reports/teacher/` — закрытые методические карточки с эталонными проверками;
- `docs/COVERAGE_MATRIX.md` — связь лабораторных с лекционными темами;
- `docs/DEMO_EXAM_ALIGNMENT.md` — проверка готовности по КИМ 09.02.07-5-2027;
- `SOURCES.md` — официальные источники и ограничения применимости.

## Локальная проверка

Требуется Node.js 22.13 или новее и pnpm.

```bash
pnpm install
pnpm run sync:public
pnpm run check
pnpm run dev
```

Студент сдаёт один заполненный редактируемый DOCX в LMS. Пароли, токены и персональные данные в отчёт не включаются.

Для квалификации **«специалист по информационным системам»** используется актуальная карточка [КИМ 09.02.07-5-2027](https://bom.firpo.ru/Public/6506). В LR05 последнего семестра приложена сквозная офлайн-репетиция шести заданий и 30 индивидуальных вариантов; границы прямого и междисциплинарного покрытия зафиксированы отдельно.
