# МДК.07.01 — лабораторные работы

22 работы, 30 вариантов, семестры 6, 7 и 8. Сохранены исходные номера, названия и максимумы: 70, 100 и 50 баллов соответственно. Оболочка перенесена на React/TypeScript/Vite из `2026-lab-shablone`, версия исходного шаблона `2a8a1aed7d037a85d6fcc650da09698476bd0439`.

## Работа с проектом

Нужны Node.js 24 и npm. Выполните `npm ci`, `npm run check`, `npm run build`. Локальный запуск: `npm run dev`. Готовый статический сайт находится в `dist`; GitHub Actions публикует его в Pages.

Актуальные задания — `src/data/labs.json`, вариантные наборы — `src/data/datasets.json`, методические объяснения — `src/data/methodology.ts`, реквизиты — `src/config.ts`. Разрешение варианта единое для страницы и экспортов: `src/lib/resolveLab.ts`.

В каждой работе доступны редактируемый DOCX, автономный HTML, CSV с BOM UTF-8 и разделителем «точка с запятой», исходные SQL/JSON/YAML и инструкция запуска стенда. В ZIP сохранена дополнительная папка «Стенд»: она необходима для исходных работающих компонентов курса. Студент сдаёт один заполненный DOCX в LMS. Ни сайт, ни архив не отправляют отчёт автоматически.

Полный публичный комплект преподавателя содержит все 660 сочетаний работ и вариантов. Закрытые ключи и внутреннее планирование передаются отдельно и не входят в сайт. Ссылок и отсылок к лекциям в заданиях и экспортах нет. DOCX нейтрален к варианту: студент заполняет номер, а исходные данные берёт из своего HTML/CSV.

## Стенды и изменения

Сохранены исходные SQL-схема, начальные данные, ошибочные учебные запросы, заготовки процедуры и триггера, сценарии восстановления, конфигурации мониторинга и сравнительные скрипты. Исправлены генератор нагрузки MySQL, отсутствовавшие заказы для вариантов 13–30, размерности порогов мониторинга и окна журналов. Добавлены новые партии импорта, матрицы проверок и период наблюдения.

Порядок запуска и безопасного восстановления учебного состояния — `inputs/docs/stand-start.md`. Файлы-каркасы требуют самостоятельного дополнения. Windows-служба MySQL и реальная цепочка exporter → Prometheus → Grafana требуют подготовленной учебной среды; наличие автономного HTML не заменяет её.

## Документы и проверка

22 актуальные формы находятся в `public/reports/C*_S*_LR*.docx`. Они созданы из титульного листа нового шаблона и проверены через Microsoft Word. `authoring/reports.py` — генератор для установленной среды подготовки; его reference хранится в соседнем репозитории шаблона. Обычная сборка сайта не требует Python или Word и не пересоздаёт DOCX.

`scripts/sync-course.mjs` формирует каталог `site-public` по разрешённому составу. Старые файлы исходного сайта сохранены в репозитории для сверки; они не включаются в новую сборку. `authoring/original-labs.json` — неизменённый снимок первоначальных работ. Скрипты миграции фиксируют историю преобразований; не запускайте начальную миграцию поверх последующих ручных правок. При изменении набора одновременно обновляйте страницу, CSV, форму и версию данных.

`quality/` содержит отчёты выполненных проверок. Они различают автоматическую сверку, тесты СУБД, просмотр документов и браузерные проверки. Прохождение студентом целевого уровня и соответствие новому официальному тематическому плану не подтверждены.
