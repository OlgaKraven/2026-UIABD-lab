# Скрипты подготовки

Скрипты migrate.py, enrich.py, finalize-data.py, stand-data.py, fix-log-windows.py и import-variants.py — этапы первоначальной миграции, а не команда повторной сборки сайта.

После повторного выполнения исторических этапов обязательно выполните restore-original-variants.py: он восстанавливает исходный контракт вариантов. Затем выполните npm run check. Независимый снимок original-variants.json взят из исходного Git-коммита и не должен обновляться из модифицированных данных.

Для обычной сборки используйте npm ci, npm run check, npm run build. Они не перезаписывают варианты.

Распределение баллов 25/25/50 закреплено указанием пользователя и проверкой npm run check. После исторической миграции примените update-points.py и обновите Word-шаблоны; не возвращайте прежние 10 баллов всем работам. Исходный снимок нужен для истории, а не для актуального максимума.
