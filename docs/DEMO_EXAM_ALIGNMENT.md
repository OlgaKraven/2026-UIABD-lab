# Сопоставление с демонстрационным экзаменом

Проверено 1 сентября 2026 года по официальной карточке [КИМ 09.02.07-5-2027](https://bom.firpo.ru/Public/6506) и Тому 1, обновлённому 30 августа 2026 года.

Квалификация: **специалист по информационным системам**. Уровень: ГИА ДЭ базовый. Максимальная продолжительность инвариантной части: **3 ч. 30 мин.**

## Структура КИМ 2027

| Задание | Официальный результат | Время | Подготовка в комплекте |
| ---: | --- | ---: | --- |
| 1 | ER-диаграмма в 3НФ с ключами и связями | 20 мин. | учебный вариант в офлайн-репетиции; проектная модель в ПИДИС |
| 2 | База по ER-диаграмме и импорт `Заказчики.json` | 30 мин. | C3_S6_LR03–LR04 и офлайн-репетиция |
| 3 | Запрос полной стоимости заказа | 20 мин. | C4_S7_LR01–LR05, прямое ядро — LR04–LR05 |
| 4 | Модуль информационной системы по ТЗ | 60 мин. | сквозная работа с ПИДИС; авторизация, капча, блокировка и АРМ администратора |
| 5 | API заметок, обработка JSON и коллекция автотестов | 60 мин. | новый сквозной блок репетиции; требуется практическая реализация в курсе интеграции |
| 6 | Документация реализованного API | 20 мин. | новый шаблон проверки в репетиции; требуется API-ориентированная документация |

Официальное распределение 75 баллов: соадминистрирование БД и серверов — 17; проектирование и разработка информационных систем — 33; интеграция программных модулей — 25.

## Готовность последнего семестра

Пять лабораторных 8 семестра **не являются самостоятельной полной заменой КИМ**. Их назначение — наблюдение, интерпретация отклонений, диагностика, восстановление и сравнение платформ. Это поддерживает критерии соадминистрирования, но прямые экзаменационные артефакты создаются накопительно:

- задания 1–3 — через результаты предыдущих семестров и приложенную офлайн-репетицию;
- задание 4 — через ПИДИС и программную реализацию;
- задание 5 — через отдельную реализацию API и коллекцию автоматизированных тестов;
- задание 6 — через документацию именно фактически реализованного API.

В LR05 последнего семестра добавлен комплект из 30 вариантов, учебный аналог `Заказчики.json`, 30 API-кейсов, манифест доказательств и чек-лист полной репетиции заданий 1–6.

## Выявленный разрыв между редакциями

Материалы ПИДИС, подготовленные под предыдущую редакцию, сохраняют полезное прямое покрытие задания 4. Однако прежняя маркировка «модуль 5 — проектная документация» устарела: в КИМ 2027 задание 5 — это API с автотестами, а документация API стала заданием 6. До зачёта полной готовности нужен успешный офлайн-прогон API, трёх обязательных тестов и документации по фактическому ответу сервиса.

## Контрольный прогон

Готовность подтверждается только если студент без Интернета за 3 ч. 30 мин. создаёт все шесть артефактов, а проверяющий воспроизводит скрипты, приложение, API-тесты и примеры документации без устных пояснений автора.
