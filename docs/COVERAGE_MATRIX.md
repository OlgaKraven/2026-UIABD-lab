## Контроль границ дисциплины

- Модель данных предоставлена готовой; построение и нормализация не оцениваются.
- SQL применяется на серверной базе, но теория языка не преподаётся заново.
- Восстановление копии выполняется технически; политика резервного копирования не разрабатывается.
- MySQL — основная платформа; PostgreSQL используется в сравнительной работе.
- Prometheus и Grafana представлены как допустимый учебный стек, а не единственный вариант.
